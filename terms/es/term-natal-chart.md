# ¿Qué significa Carta natal en astrología?

Representación calculada para la fecha, hora y lugar de nacimiento; ofrece la base de una lectura natal dentro de la tradición elegida.

## ¿Cómo se interpreta?

Registra la precisión de los datos, el zodíaco y el sistema de casas. Si falta una hora fiable, deja sin confirmar las capas que dependen de ella.

## Ejemplo

La Luna natal describe la posición calculada para el nacimiento, no la posición lunar de hoy.

## Una pregunta para ti

> ¿Esta posición pertenece al momento del nacimiento o a otra fecha seleccionada?

## ¿Cuál es el error habitual?

Una carta natal no es una medida científica de personalidad o destino y no cambia con el cielo diario.
